# Суфлёр X2 — 1.1.0

Версия 1.1.0 (versionCode 3) добавляет импорт своего текста и офлайн-слежение за русской речью. Пакет `dev.rayneo.teleprompter`, прежний постоянный ключ подписи. APK рассчитан на ARM64 и Android 12+, включая RayNeo X2.

## Импорт текста

Удерживайте дужку, чтобы открыть меню. Свайпами выберите «Импорт .txt — выбор файла», затем коснитесь дужки. Выберите обычный UTF-8 файл до 512 000 байт. Текст копируется в приватное хранилище приложения, и исходный файл после импорта больше не нужен. Отмена, пустой файл, неверная кодировка или слишком большой файл не заменяют прежний текст.

Если в прошивке очков нет системного файлового диалога либо им неудобно управлять, используйте USB-импорт. После первого запуска приложения:

```sh
adb push /absolute/path/to/speech.txt /sdcard/Android/data/dev.rayneo.teleprompter/files/import/speech.txt
```

Затем в меню выберите «Импорт по USB — speech.txt». Этот путь работает с подписанным release APK, без root и без `run-as`. Файл в папке import можно удалить после успешного импорта. `upload-release-text.sh` выполняет загрузку на подключённые очки; импорт подтверждается на самих очках.

## Голосовое слежение

В меню выберите «Голосовое слежение · русский» и разрешите доступ к микрофону. При первом включении распаковывается встроенная русская модель Vosk; дождитесь статуса «ГОЛОС · RU». Модель входит в APK, скачивание на очках и Google Speech не нужны.

Читайте текст с текущего места. Приложение сопоставляет распознанные фразы с ближайшими словами сценария и прокручивает к произнесённой строке. Пунктуация, переносы строк и различие е/ё не мешают поиску. Одиночные слова и повторяющиеся частичные результаты не вызывают скачок. Небольшие ошибки распознавания допускаются; произвольный пересказ и числа цифрами могут не совпасть с написанием в тексте.

Касание останавливает голосовой режим. Свайп также останавливает микрофон и позволяет вручную найти нужную строку; затем голос можно включить снова. При переходе в меню, сворачивании или выходе микрофон освобождается. Автоматическая прокрутка с фиксированной скоростью и голосовой режим не работают одновременно.

Сейчас встроена русская модель. Тексты других языков можно импортировать и читать с автопрокруткой, но голосовое слежение для них не заявлено. Точность зависит от дикции, шума и совпадения речи со сценарием. В поиске используется ограниченный участок около текущего места; после большого пропуска переместитесь свайпами.

## Управление

| Жест | Чтение | Меню |
| --- | --- | --- |
| Касание | Старт/пауза автопрокрутки; остановка голоса | Выбрать пункт |
| Свайп | Скорость при автопрокрутке; строка на паузе | Предыдущий/следующий пункт |
| Удержание | Открыть меню | Закрыть меню |
| 3 касания | Размер шрифта | Без действия |
| 2 касания | Выход | Назад к тексту |

Возврат к началу теперь находится в меню. Это изменение относительно 1.0.1.

## Данные и разрешения

Запрашивается RECORD_AUDIO только при включении голосового режима; MODIFY_AUDIO_SETTINGS используется для режима микрофонов X2 `voiceassistant`, который выделяет голос владельца очков. При остановке устанавливается `audio_source_record=off`.

Звук обрабатывается на устройстве и не записывается в файлы. Распознанные фразы используются в оперативной памяти для поиска позиции; на сервер они не отправляются. Разрешения INTERNET нет. Импортированный текст, позиция, скорость и размер шрифта сохраняются локально. Модель хранится в каталоге без резервного копирования. Старые материалы магазина 1.0.1, утверждающие отсутствие микрофона и импорта, для новой версии неприменимы.

## Проверка

Проверки и итоговые отчёты находятся в `releases/verification-1.1.0/`. Тесты используют отдельный test APK, синтетическую русскую аудиофразу и Android 12 ARM64 Emulator. Они не заменяют проверку реальных микрофонов, жестов и оптики на RayNeo X2. Физические очки в этой сессии не подключались.

## Источники и зависимости

- [Vosk Android](https://alphacephei.com/vosk/android), версия 0.3.47, JNA 5.13.0 — совместимые с текущим Android Gradle Plugin версии.
- [Русская модель vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models), Apache 2.0, примерно 45 МБ. Лицензия включена в assets.
- [Режимы микрофона RayNeo](https://rayneo-en.gitbook.io/rayneo-devdoc/x-series/android-sdk/capabilities-and-api/audio-capture-modes).

Для повторной сборки нужны прежние JDK/Android SDK и `./build-release.sh`. При переносе проекта вместе с соседним каталогом rayneo-signing путь к старому ключу определяется по имени файла. Новые ключи не создаются.
